Questions fréquentes

Vous avez une question ?

Faut-il un compte bancaire pour utiliser Orena ?

Non. Votre numéro de téléphone suffit pour créer votre compte. Vous alimentez ensuite votre portefeuille auprès d’un agent Orena.

Mon argent est-il en sécurité ?

Oui. Chaque opération est protégée par votre code secret, ou par votre empreinte digitale si vous l’activez. Ne communiquez jamais votre code à personne, pas même à un agent.

J’ai envoyé de l’argent au mauvais numéro. Que faire ?

Ouvrez l’opération dans votre historique et faites une réclamation. Notre équipe examine la demande rapidement.

Combien coûte une opération ?

Les frais dépendent du service. Ils sont toujours affichés dans l’application avant que vous ne confirmiez : vous savez exactement ce que vous payez.

Je vis à l’étranger. Puis-je utiliser Orena ?

Oui. Orena propose un espace dédié aux Maliens de France, des États-Unis, du Canada et de Chine, avec les montants affichés dans votre devise.

Comment devenir agent Orena ?

Écrivez-nous avec le formulaire ci-dessus en choisissant « Devenir agent Orena ». Nous vous expliquerons les conditions et les démarches.
